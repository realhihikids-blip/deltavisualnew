# DELTA VISUALS (Fabric, Minecraft 1.21.11)

Client-side visual mod: ClickGUI, HUD, markers, binds, configs.
No combat/cheat features (no KillAura, aimbot, hitbox changes, anticheat bypass).

## Build (GitHub, no installs)
1. Upload the CONTENTS of this folder to the root of a GitHub repository
   (settings.gradle must be in the root; the .github folder too).
2. Open Actions -> wait for the green check -> Artifacts -> delta-visuals.
3. Inside: delta-visuals-0.2.0.jar (not the -sources one).

## Install
Minecraft 1.21.11 + Fabric Loader 0.18+ + Fabric API for 1.21.11.
Put Fabric API and delta-visuals-0.2.0.jar into .minecraft/mods.

## Use
Right Shift opens the menu (changeable in Settings).
LMB on a module = on/off. RMB = settings and Bind.
Configs are stored in .minecraft/config/deltavisuals/.
